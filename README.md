# BMI-Generator
BMI Generator A simple Body Mass Index (BMI) calculator built using HTML, CSS, and JavaScript. This tool allows users to input their weight and height to quickly calculate their BMI and determine their weight category. 
# Features
- User-friendly interface with responsive design
- Instant BMI calculation based on user input
- Categorizes BMI results (Underweight, Normal, Overweight)
- Lightweight and easy to integrate into other projects

# Usage
- Enter your weight and height in the respective input fields.
- Click the "Calculate" button.
- View your BMI result and category instantly.

# Technologies Used
- HTML – Structure and layout
- CSS – Styling and design
- JavaScript – Dynamic calculation and interaction
